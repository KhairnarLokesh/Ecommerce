- `SECURITY.md` – Security hardening audit report (Phase 8)
- `TEST_REPORT.md` – End-to-end testing matrix (Phase 9)
- `DEPLOYMENT.md` – Production shared hosting and cPanel setup runbook (Phase 10)
- `BACKUP_RESTORE.md` – Automated & manual backup procedures (Phase 10)
- `ADMIN_GUIDE.md` – Client administrative guide (Phase 10)
- `MAINTENANCE.md` – Ongoing code and server maintenance procedures (Phase 10)
- `HANDOVER.md` – Deliverables and ownership signoff checklist (Phase 10)
